## What shipped

- **`EnvironmentBodyParser` + `EnvironmentBody`** (`src/constructs/environment_parser.rs`, public) — the decided parameterized core parser (§3.6 "slot terminators are parser business"). Runs a `Command`-stop `NodesParser` with `consume = false` — the decided *manual post-stop lookahead*, since the consume decision hinges on the name group after `\end`, invisible at the stop point — then reads the rigid name group, verifies the back-reference, and stages the body `List` over the content interior (empty body = empty `List`). Both the body and the terminator are read under `cx.state` = the slot's state (caller-scoped, like arguments). Output: the `List`'s `BuildId` + the environment's end position (past the consumed terminator, or the body's end when it closed without consuming). No after-effect delta.
- **Rigid name-group reading** (`read_rigid_name_group`, pub(crate)) — shared by the terminator flow and the test composition's `\begin` side: a group open of the configured class as the *immediately next token* (empty pre-space; the introducing command's own post-space is the tolerated, unrecorded gap — `\end {name}` works, `\end\n\n{name}` and `\end%c{name}` don't), chars-only interior with **no whitespace** (`{ A }` is malformed), the matching close. Any deviation: nothing consumed, caller recovers. The interior is read under the memoized `group_interior_state` derivation so the close is guaranteed recognizable.
- **Decision-8 recovery matrix**, all paths tested tolerant + strict: name mismatch → diagnostic + close **without consuming** (unwinding verified: `\begin{A}x\begin{B}y\end{A}` — B diagnosed and closed, A consumes its own terminator); malformed terminator → diagnostic + consume the terminator **command alone** + close (the name-group bytes re-parse as enclosing content — `\end[y]`, `\end{ A }` shapes pinned by tests); end of input → missing-terminator diagnostic anchored at the invocation trigger (the `GroupParser` unclosed-at-open precedent), nested unterminated environments each diagnose their own; unexpected group close in the body → diagnostic + unwind without consuming (`{\begin{A} x } y`: the enclosing group then claims its close — one honest diagnostic).

## Implementation decisions to sign off (filled per decided principles; none contradicts a recorded decision)

1. **The composition stayed test-side.** The plan allowed promoting it to a core helper "only if it proves nontrivial". It *is* substantial (~120 lines), but its shape is dominated by preset-policy questions (how `\begin` resolves to an environment name+spec, unknown-environment recovery) that Phase 7 should decide — so core got the two reusable pieces (`EnvironmentBodyParser`, `parse_declared_arguments`, `read_rigid_name_group`) and the composition stays a rehearsal. Revisit at Phase 7 with flagged item 5 in hand.
2. **`EnvironmentBodyParser::new(trigger_span, invocation_name, stop_command_name, name_group_type)`** — two adjustments to the sketched `{stop_command_name, name_group_rule/type, match_invocation_name}` params: (a) `trigger_span` added as the missing-terminator diagnostic's anchor (pointing at the `\begin{itemize}` that opened is the useful message; `GroupParser` anchors unclosed-group at its open span the same way); (b) `invocation_name` is always required (every diagnostic names the environment) and `match_invocation_name` became the builder switch `with_match_invocation_name(bool)` (default true; disabled = any rigid name group closes, pinned by a directly-driven test). "Rule/type" resolved to **type**, matching `GroupArgumentParser`'s parameterization.
3. **Malformed-terminator "consume" = the terminator command alone.** Decision 8 says diagnose + consume + close; pinned here: exactly the `\end` token (post-space included) is consumed, and whatever follows re-parses as enclosing content (`\end[y]` → sibling `[y]`; `\end{ A }` → sibling group). Rationale: the command is the token whose re-cascading decision 8 forbids; consuming beyond it would eat content on a guess.
4. **Stray group close in the body**: not in the plan's 6.6 recovery list, resolved by decision 8's loop-safety rule ("every level consumes or unwinds") — diagnostic (missing terminator) + close without consuming, the `GroupParser` unwinding analog. The stray close then reaches a level that claims it (the enclosing group's own close consumes silently — one diagnostic total; at the root, the root's diagnose-and-skip adds its own — two, both honest).
5. **Lifetime finding for Phase 7 (the preset's `EnvironmentSpec`):** a composition running inside `parse(cx)` cannot mint a *new* `Invocation` carrying the resolved environment name — `Invocation.name: &'s str`, and the `'s` source content is unreachable through `cx` (the source is `Arc`-owned; tokens carry only byte spans). So a two-level dispatch (begin-spec → env-spec's own `make_invocation_parser`) does not work with the current `Invocation` shape; the test composition instead drives `EnvironmentBodyParser` directly under the resolved spec. Related: a stored trigger token cannot be handed back to `cx.tokens` (invariance through the uniform `parse` signature — the known 6.3 finding), so the takeover's "`move_past(token, false)`" reposition idiom is expressed positionally via `resume_at`; the 6.4 module-docs phrasing of that idiom should be adjusted when this is reviewed.
6. **Begin-side recovery (test-lang, informative for Phase 7):** malformed `\begin` (no rigid name group) → diagnostic + chars fallback over the trigger alone, nothing further consumed (the unresolvable-command artifact pattern); unknown environment → diagnostic + a minted argument-less single-slot fallback spec so the body still parses to its terminator (the §specs unknown-callable-fallback pattern, per-instance here; a preset would register a shared singleton via `LibraryStack::set_fallback`).
7. **The body `List` records the slot state** (`cx.state` at body-parse time), i.e. the state its content was parsed under — the environment node itself records the invocation's base state (staged after the structural revert). Contrast: a `Group` node records the *outer* state; the `List` is an interior region, not a delimiter-bearing construct, so the interior state is the honest one.
8. **Tokenizer error mid-terminator** = the 6.5 probe rule: strict aborts with the token error; tolerant treats the position as unusable (malformed terminator) *without* diagnosing the token error — the enclosing loop re-reads it and applies its own recovery (no double report).
