## Implementation decisions to sign off (unrecorded details, filled following pylatexenc parity / decided principles — none contradicts a recorded decision)

1. **Requires-args-in-expression recovery.** The decided diagnostic fires when a callable declaring arguments/slots appears in single-expression position; tolerant recovery stages the **bare single-token callable** (trigger alone, every declared argument absent — the record stays self-describing) and consumes nothing past the trigger. Matches pylatexenc (`\frac\sqrt2`: `2` stays available to `\frac` rather than being swallowed by `\sqrt`). The alternative — dispatching the full invocation anyway — was rejected as deviating from both pylatexenc and TeX.
2. **Optional-group nesting — RESOLVED by user decision (July 2026, post-6.5 review): brackets balance, pylatexenc parity.** As first shipped, the minted rule was momentary (opening delimiter only) and the first `]` closed, TeX-style. On review the user chose pylatexenc's semantics: the minted rule (still **prepended**, winning ties; matched by `Arc` identity) is in force for the argument's whole extent, so `\item[with[recursive[use]of]brackets]` is **one** argument with nested `[…]` group nodes — while every child descent that is *not* a minted-rule group (brace groups, invocations) reverts to the argument's state, so `[{arg with ]}]` and `\item[\m{a]b}]` keep their brace protection. This is pylatexenc's `make_child_parsing_state` expressed through `ChildStateSpec` (`GroupParser` gained per-use `with_child_states`, default `Inherit`); shapes verified against pylatexenc 3.0a33. Recorded as a new DESIGN_RATIONALE §3.6 entry, including the accepted pitfall: protection rides one bracket level (pylatexenc's depth-2 behavior already contradicts its own docstring and mangles `[a[{x]y}b]` silently; techy mangles it with diagnostics). **Follow-up direction decided (user):** the depth-N fix will be temporary group rules scoped in core state data, stripped in the pure derivation path on a non-temporary `expecting_group_close` — not a `Lang` callback, not the session; recorded as the entry's *Revisit* note with its three open sub-questions, to ship seam + semantics together in a later session.
3. **Lone-group unwrap is opt-in and optional-only.** `OptionalGroupArgumentParser::with_unwrap_lone_group(group_type)` designates the children of a lone child group of that class (`[{arg with ]}]` — the decided §3.5 example) as content; no privileged `{}` spelling, no unwrap on the mandatory parser (the decided `\textbf{abc}` designation is the outer group's children). Extend to the mandatory parser only if a consumer demands it.
4. **Content designation split.** Matched delimited form → `InChildrenOf` (delimiters are argument syntax); any expression (fallback or standalone), including a group expression of a *different* class → `InRegion` on the node itself (its delimiters are part of the value, e.g. a math group).
5. **Tokenizer error while probing an argument.** Strict: abort with the token error (as the loop would). Tolerant: report the argument absent *without* diagnosing or consuming — the enclosing loop re-reads the error and applies its own token recovery, avoiding a double report. (A missing-mandatory diagnostic may still fire alongside; two diagnostics, both honest.)
6. **Expression-position after-effect deltas are dropped** — forced by the decided `parse_argument` signature (no delta channel); pinned by a test (a takeover invocation-as-argument returning a comments-off delta does not affect siblings).
